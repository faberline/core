# DDD P1 source paths

P2 changes are in [ddd-p2.md](ddd-p2.md); later source paths are in
[ddd-p2-paths.md](ddd-p2-paths.md).

Where each Rust source file under `crates/*/src/` at main (`ec842d6`) is after
P1. See [ddd-p1.md](ddd-p1.md) for what P1 changed.

The table was generated by matching item names between main and P1: the
functions, types, traits, constants and macros each old file defines at top
level, or, for a file with none, its method and test function names.

- A file split into several files lists them, most items first; long lists
  end with the number of further files.
- **unchanged** means the file is at the same path with the same content.
- **module declarations and re-exports** means the old file only declared
  modules; its public path is now a compatibility facade under `src/compat/`
  or the crate's `lib.rs`.
- **module declarations only; its modules moved to** names the directories
  that hold the old module's children.
